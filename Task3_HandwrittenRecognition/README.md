
# Handwritten Character Recognition Using CNN

## CodeAlpha Machine Learning Internship — Task 3

### Project Overview
This project recognizes handwritten digits (0–9)
using a Convolutional Neural Network (CNN).

### Dataset
- Name: MNIST Handwritten Digits
- Training Images: 60,000
- Testing Images: 10,000
- Image Size: 28 × 28 pixels
- Classes: 10 (digits 0–9)

### Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

### CNN Architecture
1. Conv2D - 32 filters, ReLU
2. MaxPooling2D
3. Conv2D - 64 filters, ReLU
4. MaxPooling2D
5. Flatten
6. Dense - 128 neurons, ReLU
7. Dense - 10 neurons, Softmax

### Model Performance
- Test Accuracy: 98.79%
- Test Loss: 0.0355

### Features
- Handwritten digit recognition
- CNN-based image classification
- Training and validation visualization
- Confusion matrix
- Incorrect prediction analysis

### Results
The CNN achieved 98.79% accuracy on the
MNIST test dataset.

### How to Run
1. Open the Jupyter notebook in Google Colab.
2. Install the required libraries.
3. Run all cells sequentially.
4. View the evaluation results and predictions.
