
# CodeAlpha Machine Learning Internship Projects

## November 2026 Batch

This repository contains three Machine Learning
projects completed as part of the CodeAlpha
Machine Learning Internship.

## Completed Tasks

### Task 1: Credit Scoring Model
Predicts credit risk using historical financial data.

- Dataset: German Credit Dataset
- Models: Logistic Regression, Decision Tree,
  Random Forest
- Best Model: Logistic Regression
- Accuracy: 78%
- ROC-AUC: 0.8040

[View Task 1](Task1_CreditScoring)

### Task 3: Handwritten Character Recognition
Recognizes handwritten digits (0-9) using
a Convolutional Neural Network.

- Dataset: MNIST
- Model: CNN
- Reported Accuracy: 98.79%
- Test Loss: 0.0355

[View Task 3](Task3_HandwrittenRecognition)

### Task 4: Disease Prediction
Classifies breast tumor samples as benign or malignant
using machine learning algorithms.

- Dataset: Breast Cancer Wisconsin (Diagnostic)
- Models: Logistic Regression, SVM, Random Forest
- Best Model: Logistic Regression
- Accuracy: 98.25%
- ROC-AUC: 0.9954

[View Task 4](Task4_DiseasePrediction)
